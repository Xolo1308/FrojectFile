Cài đặt SecureShield trên trình duyệt

Thực hiện theo các bước dưới đây để cài đặt tiện ích bảo vệ bạn khỏi các website lừa đảo.

1

Tải file Extension

Nhấn vào nút bên dưới để tải file SecureShield.crx về máy tính của bạn.

Tải SecureShield.crx
2

Mở trang quản lý tiện ích

Mở trình duyệt Chrome và nhập địa chỉ sau vào thanh URL:

chrome://extensions/
Bạn cũng có thể truy cập bằng cách: Menu (⋮) → Tiện ích mở rộng → Quản lý tiện ích.
3

Bật chế độ Nhà phát triển

Tại góc trên bên phải của trang chrome://extensions/, bật công tắc:

Chế độ nhà phát triển (Developer mode)
Sau khi bật, bạn sẽ thấy thêm các nút chức năng mới.
4

Kéo thả file .crx vào trình duyệt

Kéo file SecureShield.crx từ thư mục Downloads thả vào trang chrome://extensions/.

Hoặc nhấn nút Tải tiện ích đã giải nén và chọn thư mục chứa file.
Kéo thả file .crx vào đây
(Hình ảnh minh họa)
5

Xác nhận cài đặt

Trình duyệt sẽ hiển thị hộp thoại xác nhận. Nhấn Thêm tiện ích để hoàn tất.

Sau khi cài đặt, biểu tượng sẽ xuất hiện trên thanh công cụ.
